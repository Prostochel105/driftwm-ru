# Changelog

## V5.3 — 2026-11-11

### Исправлено
- Иконки на старых карточках больше не залипают чёрными кружками после неудачной
  загрузки (например, во время обновления приложения или пока список приложений
  ещё загружался). Кэш теперь повторяет загрузку, когда приложение снова доступно,
  при обновлении списка и при возврате на рабочий стол.
- Подписи экранов «Настройки Drift» и «Диагностика Drift» локализованы.
- `app_name` больше не конфликтует с `translatable`; lint проходит без ошибок.
- Язык интерфейса (`L.isRu`) читается динамически, а не один раз при старте.

### Изменено
- Версия сборки: `V5.3`; CI добавляет номер запуска к `versionName` и использует
  его как `versionCode`, чтобы каждая сборка ставилась поверх предыдущей.
- В предпросмотре настроек убраны аллокации `RectF` из `onDraw`.
- Добавлены `CHANGELOG.md`, `.gitattributes` и требования к установке в README.

## V5.2 — 2026-11-10

Первый публичный релиз русской сборки.

- Полностью русский интерфейс по системному языку.
- Новый экран настроек: предпросмотр, 6 тем, фон/картинка, акцентный цвет,
  статусы превью и батареи, быстрые переходы.
- Встроенная справка по жестам.
- Фиксированный debug-ключ и растущий `versionCode`: обновления ставятся поверх
  без потери раскладки.
- GitHub Actions собирает APK, релиз `v5.2` содержит готовый файл.
