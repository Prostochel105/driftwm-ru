# Changelog

## V5.6 — 2026-11-14

Включает хотфикс 5.5.2 (отдельно не выпускался).

### Добавлено
- **Пустые папки в доке.** Долгое удержание пустого слота открывает меню
  «Добавить приложение / Создать папку». Созданная из пустого слота папка сразу
  открывается и содержит один свободный слот «+»; после добавления приложения
  рядом появляется ещё один свободный слот. Удаление последнего приложения
  оставляет папку со свободным слотом, а не пустой слот дока. На доке пустая
  папка рисуется плиткой с «+».
- **Перетаскивание иконок внутри папки.** Долгое удержание приложения в папке
  подсвечивает его и открывает меню («Открыть», «Убрать из папки»). Если, не
  отпуская, начать двигать иконку, меню исчезает и она «летит» за пальцем: бросьте
  на другое место — порядок меняется, бросьте за пределы папки (на затемнённый
  фон) — приложение убирается из неё (с подтверждением). Порядок больше не
  привязан к порядку добавления.
- Справка «Папки в доке» в настройках и раздел README обновлены под новый сценарий.

### Исправлено
- **Приложение действительно добавляется в папку.** «+» в папке открывал список
  напрямую из Java, минуя ядро, поэтому выбранное приложение никуда не попадало:
  ядро решает по своему `drawer_pick`, а его выставлял только `open_drawer`.
  Теперь «+» идёт через ядро (`Native.dockAddApp`), и папка наполняется.
- **Пустой слот дока:** обычный тап — выбрать приложение; меню (создание папки)
  открывается долгим удержанием.

### Из хотфикса 5.5.2
- **Большие папки прокручиваются.** Сетка ограничена по высоте (74% экрана) и лежит
  в `ScrollView`; нижние ряды и «+» больше не уезжают за экран. Иконки, пришедшие
  после открытия папки, дозаполняются без пересборки всей сетки.
- **Попап папки пересчитывает размеры** после поворота и изменения размера окна.
- **Уменьшение дока спрашивает подтверждение**, если удаляемые слоты не пусты: раньше
  приложения и папки из них пропадали молча.
- **Версия формата состояния поднята до 2.** Файлы v5.5.1 с папками больше не
  притворяются совместимыми со старыми сборками; состояние v1 по-прежнему читается.
- **Release-сборка вместо debug:** workflow собирает `assembleRelease`, поэтому APK
  больше не `debuggable`. `allowBackup` отключён.
- **`versionCode` начинается с 101** — сборки форка ставятся поверх официальных 7–9.
- **Ссылка «О проекте»** ведёт на этот репозиторий, а не на upstream.
- **Проверка службы превью** понимает короткую форму компонента (`pkg/.Service`),
  которую пишут некоторые прошивки.
- **CI запускает `cargo test` и `cargo clippy`;** пуш тега `v*` публикует GitHub Release.

## V5.5 — 2026-11-14

### Добавлено
- **Папки в доке.** Долгий тап по слоту → «Создать папку»: приложение из слота
  становится папкой, которую сразу можно наполнить. Тап по папке открывает её
  содержимое: тап — открыть приложение, долгий тап — убрать из папки, «+» —
  добавить ещё, тап по названию — переименовать. Долгий тап по папке в доке —
  переименовать или убрать из дока.
- **Количество слотов в доке.** В настройках (Интерфейс → «Приложения в доке»)
  можно выбрать от 3 до 8 слотов. Значение хранится вместе с раскладкой.

### Изменено
- Док подстраивает размер слотов под их число, поэтому 8 слотов помещаются даже
  на узких экранах, не задевая кнопку списка приложений.

### Совместимость
- Старые раскладки (док как список строк) читаются без изменений; папки — новый
  формат, который старые версии просто не увидят.

## V5.4.2 — 2026-11-13

### Добавлено
- **Возврат туда, где вы были.** Перед запуском приложения Drift запоминает
  положение и масштаб холста, а при возврате домой сразу показывает тот же вид —
  без «прыжка» к карточке, которую открывали.
- Иконки приложений кэшируются на диск: после перезапуска лаунчера (Android
  часто выгружает его, пока вы в другом приложении) они берутся из кэша, а не
  рисуются заново из системы.

### Исправлено
- Конечное положение холста после инерционной прокрутки теперь сохраняется
  сразу, а не только при уходе из лаунчера, — вид не откатывается назад, если
  система выгрузит Drift.

## V5.4.1 — 2026-11-13

### Изменено
- Плашка **«Вернуться домой»** теперь ждёт 1,5 секунды, а не 0,3: она не мелькает,
  пока карточки ещё загружаются.
- Возврат на рабочий стол стал легче:
  - сохранение состояния при уходе из лаунчера больше не делает `fsync` в главном
    потоке;
  - список приложений запрашивается раньше и не заставляет карточки ждать
    неудачных запросов иконок;
  - иконки и миниатюры декодируются параллельно в фоне с низким приоритетом,
    а обновление экрана после пачки миниатюр происходит один раз.
- В диагностику добавлен раздел **Performance** с таймингами запуска, `onResume`
  и отрисовки — по нему видно, холодный ли это старт или задержка отрисовки.

## V5.4 — 2026-11-13

### Добавлено
- Всплывающая плашка **«Вернуться домой»**, если на экране не осталось ни одной
  карточки. Пустой холст по-прежнему бесконечный, но вернуться к карточкам можно
  одним нажатием — плашка показывает все карточки сразу.

### Изменено
- Кадр больше не рассчитывается дважды: display list рендерится один раз.
- Список приложений не запрашивается заново при каждом возврате на рабочий стол:
  изменения пакетов по-прежнему приходят через `LauncherApps`, а полный опрос
  выполняется не чаще раза в минуту.
- Если список приложений не изменился, ядро не получает его повторно.

## V5.3 — 2026-11-11

### Исправлено
- Иконки на старых карточках больше не залипают чёрными кружками после неудачной
  загрузки (например, во время обновления приложения или пока список приложений
  ещё загружался). Кэш теперь повторяет загрузку, когда приложение снова доступно,
  при обновлении списка и при возврате на рабочий стол.
- Подписи экранов «Настройки Drift» и «Диагностика Drift» локализованы.
- `app_name` больше не конфликтует с `translatable`; lint проходит без ошибок.
- Язык интерфейса (`L.isRu`) читается динамически, а не один раз при старте.

### Изменено
- Версия сборки: `V5.3`; CI добавляет номер запуска к `versionName` и использует
  его как `versionCode`, чтобы каждая сборка ставилась поверх предыдущей.
- В предпросмотре настроек убраны аллокации `RectF` из `onDraw`.
- Добавлены `CHANGELOG.md`, `.gitattributes` и требования к установке в README.

## V5.2 — 2026-11-10

Первый публичный релиз русской сборки.

- Полностью русский интерфейс по системному языку.
- Новый экран настроек: предпросмотр, 6 тем, фон/картинка, акцентный цвет,
  статусы превью и батареи, быстрые переходы.
- Встроенная справка по жестам.
- Фиксированный debug-ключ и растущий `versionCode`: обновления ставятся поверх
  без потери раскладки.
- GitHub Actions собирает APK, релиз `v5.2` содержит готовый файл.
